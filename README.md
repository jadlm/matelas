# matelas

Site vitrine Dormia pour présenter des matelas, leurs matériaux et la vidéo de marque.

## Développement local

```sh
npm ci
npm run dev
```

## Publication

Le site est publié sur GitHub Pages avec GitHub Actions. Chaque mise à jour envoyée sur `main` déclenche une nouvelle compilation et publication.

Les photos des chambres et matelas sont chargées depuis Unsplash. La vidéo locale est conservée dans `public/video/matelasvideo.mp4`.
